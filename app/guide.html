휴대폰 카메라로 QR을 비추세요

뜨는 링크를 누르면 출하앱이 열립니다.

이 휴대폰에 설치하러 가기 →
주소: https://www.ablefarm.co.kr/app/
이 안내문을 휴대폰으로 보고 있다면 QR 대신 위의 초록 단추 「설치하러 가기」를 누르세요.

안드로이드 (삼성 갤럭시 등)

  1. QR(또는 초록 단추)로 연 화면이 크롬(Chrome)인지 확인합니다.
  2. 화면 아래에 「설치」 또는 「앱 설치」 안내가 뜨면 누릅니다.
    안 뜨면 오른쪽 위 ⋮ → 「홈 화면에 추가」 → 「설치」.
  3. 홈 화면에 생긴 에이블팜 아이콘을 눌러 엽니다.
  4. 이름을 고르고 PIN 4자리를 넣어 로그인합니다.
  5. 「알림을 보내도록 허용하시겠습니까?」가 뜨면 꼭 「허용」을 누릅니다. 🔔

아이폰

  1. QR로 연 화면이 사파리(Safari)인지 확인합니다.
  2. 아래 가운데 공유 단추 ⬆ → 「홈 화면에 추가」 → 「추가」.
  3. 홈 화면의 에이블팜 아이콘으로 열고 로그인 → 「허용」.
아이폰은 iOS 16.4 이상이고, 홈 화면 아이콘으로 열었을 때만 알림이 옵니다. (사파리에서 그냥 열면 안 옵니다)
카카오톡 안에서 링크를 열면 설치가 안 됩니다.
카톡에서 열렸다면 오른쪽 아래 ⋮ → 「다른 브라우저로 열기」 → Chrome (아이폰은 Safari로 열기)을 누른 뒤 위 순서대로 하세요.

✔ 제대로 됐는지 확인

앱 맨 위 오른쪽에 🔔 가 보이면 알림이 켜진 것입니다.

  • 🔕 로 보이면 → 눌러서 켜세요.
  • 노란 띠 「🔔 알림을 켜 주세요」가 보이면 → 「알림 켜기」를 누르세요.
  • 이미 예전에 깐 에이블팜 아이콘이 있는데 🔔·🔕 가 아예 안 보이면 → 예전 방식 아이콘입니다. 그 아이콘을 지우고 위 QR로 다시 설치하세요.

  • 앱을 열거나, 알림을 누르거나, 알림을 옆으로 밀어 지우면 숫자가 줄거나 없어집니다.
  • 같은 주문의 「다시 알림」끼리는 한 칸으로 합쳐집니다. 10번 울려도 숫자가 10이 되지 않습니다.
    (주문 하나당 「주문이 있습니다」 1칸 + 「확인 안 한 주문」 1칸, 많아야 2칸)

5확인 안 하면 10분마다 다시 울립니다 ⏰ 물류

주문이 「대기」 그대로 있으면, 접수 10분 뒤부터 10분마다 알림이 다시 울립니다. 몇 번이든 계속 울립니다. (단, 접수 3일이 지난 주문은 더 알리지 않습니다)

이렇게 하면알림이 멈춥니다
알림 창의 「확인 — 준비중으로」✅ 멈춤
앱 「오늘 출고」에서 준비중 · 출고완료로 바꿈✅ 멈춤
컴퓨터에서 준비중 · 출고완료로 바꿈✅ 멈춤 (휴대폰도 같이)
알림을 그냥 옆으로 밀어 지움❌ 안 멈춤 — 10분 뒤 또 울림
  • 다시 알림은 평일 오전 8시 ~ 오후 6시에만 울립니다. 밤·주말엔 쉬었다가 다음 근무 시간에 다시 알립니다.
  • 5번째(약 50분째)에는 관리자에게도 알림이 갑니다.
  • 영업직원의 「출하완료」 알림은 한 번만 울립니다.

6안 될 때 이렇게 하세요

아래 제목을 누르면 방법이 펼쳐집니다.

🔕 알림이 안 와요
  1. 출하앱을 열고 맨 위 오른쪽이 🔔 인지 봅니다. 🔕 면 눌러서 켭니다.
  2. 휴대폰 설정 → 애플리케이션 → 에이블팜 → 알림 에서 「알림 허용」을 켭니다.
    아래에 알림 종류가 여러 개 있으면 전부 켭니다.
  3. 설정 → 애플리케이션 → 에이블팜 → 배터리 를 「제한 없음」으로 바꿉니다.
    같은 방법으로 Chrome 앱도 「제한 없음」으로 바꿉니다. (절전에 걸리면 알림이 늦거나 안 옵니다)
  4. 화면 위를 쓸어내려 방해 금지 모드가 꺼져 있는지 봅니다.
  5. 출하앱을 한 번 열었다가 닫습니다.
  6. 그래도 안 되면 관리자에게 말해 주세요.
🔢 아이콘에 숫자가 안 생겨요
  1. 설정 → 애플리케이션 → 에이블팜 → 알림 에서 「앱 아이콘 배지」를 켭니다.
    알림 종류(카테고리)가 있으면 하나씩 눌러 그 안의 「앱 아이콘 배지」도 켭니다.
  2. 설정 → 알림 → 고급 설정 → 앱 아이콘 배지 에서 「숫자 표시」를 고릅니다. (「점만 표시」면 숫자가 안 나옵니다)
  3. 알림을 이미 눌렀거나 앱을 열었다면 숫자가 없어지는 게 정상입니다.
🚫 「허용」 대신 「차단」을 눌렀어요
  1. 설정 → 애플리케이션 → 에이블팜 → 알림 → 「알림 허용」 켜기
  2. 출하앱을 다시 열면 됩니다.

아이폰: 설정 → 알림 → 에이블팜 → 알림 허용

🔐 알림을 눌렀더니 로그인 화면이 나와요

로그인이 풀린 상태입니다. 이름 · PIN으로 로그인하면 바로 그 알림 내용 창이 뜹니다.

🔇 소리가 안 나요

휴대폰이 무음·진동 모드면 그대로 따릅니다. 소리 모드로 바꾸고, 설정 → 애플리케이션 → 에이블팜 → 알림 에서 소리가 켜져 있는지 봅니다.

🙅 알림을 잠깐 끄고 싶어요

출하앱 맨 위 🔔 를 누르고 「알림 끄기」. 다시 켤 때는 🔕 를 누르면 됩니다.

물류 담당자는 끄면 새 주문을 놓칩니다. 끄지 않는 것을 권합니다.
📱 휴대폰을 바꿨거나 다른 사람이 로그인했어요

알림은 마지막으로 로그인한 사람에게 갑니다. 내 휴대폰에는 내 이름으로만 로그인하세요.
로그아웃하면 그 휴대폰으로는 알림이 오지 않습니다. 새 휴대폰은 1번 「설치하기」부터 다시 하면 됩니다.

에이블팜 출하앱 · 문의 · PIN 발급은 관리자에게 말씀해 주세요.
